Retomar · TypeScript

El contrato vuelve visibles los olvidos

Cambiar la forma de un evento convierte errores silenciosos en una lista exacta de tareas.

Definición técnica

TypeScript

TypeScript agrega tipos estáticos a JavaScript: describes de antemano la forma de tus datos y el compilador revisa todo el código, incluidas las plantillas de Angular, antes de ejecutarlo. Los tipos desaparecen al compilar: al navegador llega JavaScript.

En la vida real

Es la lista de chequeo del piloto antes de despegar. Los errores se detectan en tierra, cuando corregirlos es barato, y no en el aire, con pasajeros.

Retomar · componentes

Los datos y la pantalla quedan conectados

Un componente une clase, plantilla, estilos y selector; el data binding mantiene el resultado actualizado.

Definición técnica

Componente

Clase de TypeScript decorada con @Component, que une una plantilla HTML, unos estilos y un selector. En Angular 22 todos son standalone: cada uno declara en su propio imports lo que usa su plantilla.

En la vida real

Un molde de galletas. Se diseña una vez y se usa cuantas veces se quiera.

Tres formas de data binding

Repasotarjeta-evento.tstarima-web/src/app/components/tarjeta-evento/

Una tarjeta para todos los eventos. Recibe un Evento, calcula si está agotado o si quedan pocos cupos y usa la pieza genérica Etiqueta.

1

Recibir el evento y aplicar las reglas

La misma tarjeta cambia su resultado según el input.

Líneas 12–28
export class TarjetaEvento {
  evento = input.required<Evento>();
  mostrarDescripcion = false;

  estaAgotado(): boolean {
    return this.evento().cuposDisponibles === 0;
  }

  quedanPocosCupos(): boolean {
    const cupos = this.evento().cuposDisponibles;
    return cupos > 0 && cupos <= 10;
  }

  alternarDescripcion(): void {
    this.mostrarDescripcion = !this.mostrarDescripcion;
  }
}
  1. L13input.required<Evento>()

    La tarjeta exige un evento completo. Es lo que la hace reutilizable: la misma tarjeta, distinto evento cada vez.

  2. L16–L18estaAgotado()

    De esta regla salen la etiqueta "Agotado", el botón bloqueado y la tarjeta atenuada.

  3. L20–L23quedanPocosCupos()

    Hay cupos, pero 10 o menos. El > 0 evita que un evento agotado diga "Últimos 0 cupos".

  4. L25–L27alternarDescripcion()

    La negación cambia el estado entre abierto y cerrado. Lo llama el botón "Ver detalles".

Para pensar

alternarDescripcion() solo cambia mostrarDescripcion de false a true. En ningún archivo hay un pintar(), un innerHTML ni un querySelector. Entonces, ¿quién actualiza la pantalla?

Comprobar

Angular. Cuando ocurre un evento de la plantilla, como el (click), Angular vuelve a revisar esa tarjeta, evalúa otra vez @if (mostrarDescripcion) y actualiza solo lo que cambió. Tú cambias datos; Angular mantiene la pantalla igual a esos datos.

!

Quítala y mira

Si borras Etiqueta del arreglo imports, Angular muestra NG8001 y NG8002. Si lees evento.nombre sin paréntesis, TypeScript muestra TS2339: esa es la caja del input, no el evento.

Definición técnica

Router

El router es el servicio de Angular que relaciona cada dirección (URL) con un componente. Cuando la URL cambia, busca en una lista de rutas cuál coincide y pone ese componente en pantalla, sin recargar la aplicación.

En la vida real

Es el directorio de un centro comercial: le dices "local 204" y te lleva ahí. La lista de rutas es el directorio; la URL es el número del local.
